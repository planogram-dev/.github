# planogram-dev/.github

The public GitHub profile of Planogram Game Studio, and the default files for every repository in the organization.

| Path | What it is |
|------|------------|
| `profile/README.md` | The page at [github.com/planogram-dev](https://github.com/planogram-dev) |
| `profile/assets/` | Images for that page. They come from the studio brand files. Do not edit them by hand. |
| `SECURITY.md` | How to report a security problem in private |
| `.github/ISSUE_TEMPLATE/` | Default issue forms |
| `.github/pull_request_template.md` | Default pull request template |

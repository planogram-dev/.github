# Security

Found a security problem in a Planogram game, website, or repository? Tell us in private.

1. Email [yo@planogram.dev](mailto:yo@planogram.dev) with the subject `Security`.
2. Include the steps to reproduce, the affected game or URL, and the impact you see.
3. Do not open a public issue for a security problem.

We will contact you by email about the next steps.
